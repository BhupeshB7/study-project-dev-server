How to Run study-project-server
====================================================

This guide will help you set up and run the study-project-server backend on your Windows computer. Every step is explained for complete beginners!

----------------------------------------------------

1. Prerequisites
----------------

1.1. Node.js
- Go to https://nodejs.org/
- Click the big green LTS download button.
- Run the installer (just keep clicking Next).
- To check if it's installed:
  - Open Command Prompt (press Windows key, type "cmd", press Enter)
  - Type:
    node --version
    npm --version
  - You should see version numbers (e.g., v20.0.0)

1.2. MongoDB
- Go to https://www.mongodb.com/try/download/community
- Download the installer and run it.
- When asked for install path, you can use the default (e.g., C:\Program Files\MongoDB\Server\6.0\) or choose your own.
- Make sure to check "Install MongoDB as a Service" (recommended: Network Service user).
- When finished, MongoDB will run in the background.
- To add MongoDB to your PATH (so you can use it anywhere):
  - Open Start menu, search "Environment Variables", click "Edit the system environment variables"
  - Click "Environment Variables..."
  - Under "System variables", find "Path", click Edit
  - Click New, add: C:\Program Files\MongoDB\Server\6.0\bin
  - Click OK on all windows
- To check MongoDB:
  - Open Command Prompt
  - Type:
    mongo --version
    mongod --version
  - You should see version info. If not, check your PATH.
- To start MongoDB if not running:
  - Open Services (search in Start menu), find "MongoDB Server", right-click, Start
  - Or in Command Prompt:
    net start MongoDB

1.3. Set up MongoDB Replica Set (for advanced features)
- Stop MongoDB if running:
  net stop MongoDB
- Create a folder for data (if not already):
  mkdir C:\data\db
- Start MongoDB with replica set:
  mongod --dbpath C:\data\db --replSet rs0
- Open a new Command Prompt:
  mongosh
- In the shell, type:
  rs.initiate()
- You should see { "ok" : 1 }

1.4. Redis (using WSL - Windows Subsystem for Linux)
- Open PowerShell as Administrator (right-click, Run as administrator)
- Type:
  wsl --install
- Restart your computer if asked.
- Open Ubuntu from Start menu (it will set up, ask for username/password)
- In Ubuntu terminal, type:
  sudo apt update
  sudo apt install redis-server
- Start Redis:
  sudo service redis-server start
- To always start Redis on boot:
  sudo systemctl enable redis-server
- Test Redis:
  redis-cli ping
  (Should reply: PONG)

5. Start the Server
-------------------

7. Troubleshooting (Common Problems)
------------------------------------
- MongoDB not running?
  - Open Services and start "MongoDB Server"
  - Or run: net start MongoDB
- MongoDB command not found?
  - Check your PATH variable (see above)
- Replica set error?
  - Make sure you started mongod with --replSet rs0 and ran rs.initiate()
- Redis not running?
  - Open Ubuntu (WSL) and run: sudo service redis-server start
- Port already in use?
  - Change PORT in your .env file
- Environment variables not set?
  - Double-check your .env file
